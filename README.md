# ☕ Bearista Cafe

A full-stack web application for Bearista Cafe — a coffee shop. Built with the MERN stack, it allows customers to browse the menu, place orders, track delivery, and manage their account.

## ✨ Features

- 🛒 **Order items** from the menu
- 📦 **Track your order** in real time
- 🕓 **View order history** and reorder with one click
- ⭐ **Frequently bought items** shown for quick reordering
- 👤 **User accounts** — sign up, log in, manage your profile
- 💬 **Reviews & feedback** — leave reviews on items and the cafe

---

## 🛠️ Tech Stack

| Layer | Technology |
|---|---|
| Frontend | React |
| Backend | Node.js + Express |
| Database | MongoDB |

## 🚀 Running Locally

### Prerequisites
- Node.js (v18+)
- MongoDB (local or Atlas)
- npm

### Backend

```bash
cd server
npm install
npm run dev
```

### Frontend

```bash
cd client
npm install
npm run dev
```
